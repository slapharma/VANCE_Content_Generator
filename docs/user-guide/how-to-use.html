1   What does this tool do?

The VANCE Content Generator is the in-house content factory for Vance Medical Foods (vancemedicalfoods.com). It turns evidence sources, prompt templates, and large-language-model output into clinically-reviewed articles and social posts — and then ushers each piece through review, scheduling, and publication without leaving the app.

  • Generate long-form articles from category prompts using OpenRouter-hosted LLMs.
  • Review drafts via the Pipeline tab and secure reviewer links — no email back-and-forth.
  • Distribute on social with the built-in Kit Builder, Queue, and Connections.
  • Schedule publication using the Calendar.
  • Automate recurring content jobs with Automations + Notifications.
  • Track performance through Monitoring and Reports.
💡 The app runs entirely in the browser at vance-content.vercel.app — there is nothing to install. All data persists automatically; you do not need to "save".
📝 Everything you publish must reference Vance Medical Foods and vancemedicalfoods.com. Other branding is treated as a draft error.

Open the Generator

Click ⚡ Generate in the sidebar, or use the + New Article shortcut on the Home dashboard.

Pick a category

The category sets the prompt template, the recommended bibliography, and the visual tone. See Section 11 for how prompts are organised.

Refine the brief

Optionally narrow the topic, paste a working title, or pin specific sources from the bibliography. Anything you leave blank is filled by the prompt template.

Choose the model

Defaults to the workspace's primary model. Switch to a different one if the topic needs a longer context window or stricter structure. Free models are tagged :free.

Generate

Press ⚡ Generate. The draft appears within a few seconds and is auto-saved into the Pipeline as ready for review.

💡 Generation is best treated as a first draft. Always send it through the Pipeline (Section 5) for clinical review before publishing — the reviewer chain is what makes the output safe to ship.

Open a draft card

Click any card to see the full draft, source list, and reviewer comments.

Send for review

Click 📨 Send for Review. Pick reviewers from the user roster — each gets a unique secure link to the draft. No login required for reviewers.

Track sign-offs

The card shows each reviewer's status: pending, approved, or changes requested. Must-approve reviewers gate the next stage; reference reviewers are advisory only.

Approve & publish

Once all must-approve reviewers sign off, the card moves to Approved. Click ↑ Publish Now or schedule it from the Calendar.

⚠️ Once a card is Published, edits create a new version rather than overwriting the live copy. Use the Library to manage versions.
📝 The Home dashboard's Article Reviewing: Open Tasks section surfaces every review request currently waiting on you — a faster route in than scanning the Pipeline.

Creating a rule (5-step wizard)

Name & describe

Give the rule a memorable name. The description is purely for your team.

Pick category & prompt

The category determines which prompt the generator uses. Edit prompts on the Categories page.

Pick a model

Defaults to the workspace primary. Override if this rule needs a longer context window or a structured output model.

Set the schedule

Pick a cron pattern (daily, weekly, monthly) or a fixed time-of-day. Schedules are evaluated in GMT.

Choose approval flow

Decide whether the rule auto-files into the Pipeline as a draft, or whether it pings the Notifications inbox first for a thumbs-up. Save with ✓ Activate.

Add a source

Click + New Source. Paste a DOI, PubMed ID, or URL and the form auto-fills citation metadata.

Tag it

Tag by category and topic so the Generator can pick it up automatically. Untagged sources won't be suggested.

Mark trust level

Set the source as Preferred, Allowed, or Reference only. The LLM prioritises Preferred citations and won't cite Reference-only sources in body text.

11   Categories & Prompts

  • A coloured icon and label (visible everywhere a category appears).
  • A system prompt — the instructions the LLM follows when drafting.
  • A recommended bibliography — sources auto-suggested when generating.
  • Optional style guardrails (tone, reading level, word count).

14   Glossary

Automation rule
A configured job that generates content on a recurring schedule — e.g. "draft an IBD article every Monday".
Bibliography
The central library of sources (papers, guidelines, URLs) the Generator can cite when drafting.
Category
A topic bucket that owns a system prompt, a recommended bibliography, and visual styling.
Draft
An unpublished article. Lives in the Pipeline until approved.
Fallback chain
An ordered list of LLMs the Generator tries if the primary model fails or is rate-limited.
GMT
Greenwich Mean Time — the canonical time zone the platform uses for all schedules.
Kit (social kit)
A bundle of LinkedIn/Instagram/X/TikTok posts plus media derived from a parent article.
Library
The searchable archive of every article — drafts, approved, published, and superseded.
Must-approve reviewer
A reviewer whose sign-off is required before a draft can move from In Review to Approved.
Notifications
The approval inbox for automation runs. Approving here creates the draft and moves it to the Pipeline.
OpenRouter
The third-party API that fronts all the LLMs the Generator can call. Configured under Settings.
Pipeline
The kanban queue for drafts. Stages are Ready → In Review → Approved → Scheduled → Published.
Reference reviewer
An advisory reviewer who can comment on a draft but does not gate progression.
Social Distribution (Social tab)
The page where social posts are built, queued, posted, and connected to platforms.
Trash
Soft-deletion store. Items remain recoverable for 30 days before permanent removal.
Vance Medical Foods
The brand this platform produces content for. Production URL: vancemedicalfoods.com.
