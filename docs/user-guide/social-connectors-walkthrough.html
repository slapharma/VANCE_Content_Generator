1   What this guide covers

The Vance Content Generator is the alpha tier of a three-stage agency pipeline (alpha → beta → per-brand iterations). It already generates social posts for five platforms from a single article, but the connections themselves are still wired by hand in Vercel.

This walkthrough has three parts:

  • Part 1 — Step-by-step wiring of every social platform, with the exact Vercel environment variable names.
  • Part 2 — A tour of the "Ava" prompt kit: how five hook archetypes, three content pillars and four call-to-action templates combine to produce 300 distinct prompt shapes per article.
  • Part 3 — An audit of the image-generation pipeline, the bogus OpenRouter slugs we just removed, and what to swap to next.
💡 You do not need every platform connected at once. Start with OpenRouter (so text generation works), then add one social platform, post a test, then add the next.

3.1   OpenRouter — text + image generation

Env varOPENROUTER_API_KEY
Sign up at openrouter.ai

Create an account at openrouter.ai and add at least $10 of credit. There is no longer a usable free text-to-image tier — image generation costs roughly $0.0005 per image.

Create a key

Go to Keys → + Create Key, give it the name vance-content-prod, copy the sk-or-... value.

Paste into Vercel

Add a Vercel env var named OPENROUTER_API_KEY with that value. Redeploy.

Verify

In the app, generate a kit for any article. Watch the network tab for /api/social/generate. Six captions plus four images should come back.

3.2   FAL.ai — video generation

Env varFAL_KEY

FAL.ai runs Kling v2.1 for 10-second Reel / TikTok videos at roughly $0.35 per generation. This is the most expensive single operation in the pipeline — only wire it up once images and text are working.

Sign up at fal.ai

Create an account at fal.ai, add billing.

Generate an API key

Dashboard → API Keys → + Create. Copy the value.

Paste into Vercel as FAL_KEY, redeploy

Verify by clicking Regen Video on a generated kit — the video.url field should populate within 60-90 seconds.

3.3   Instagram

Env varsINSTAGRAM_ACCESS_TOKEN · INSTAGRAM_BUSINESS_ACCOUNT_ID
📝 Instagram posting goes through the Meta Graph API v19 — you connect the Instagram Business account that's linked to a Facebook Page. Personal IG accounts cannot post via the API.
Create a Meta app

Go to developers.facebook.com → My Apps → Create App. Pick the Business type.

Add Instagram Graph API product

In the app dashboard, click + Add Product and choose Instagram Graph API.

Request scopes

Permissions: instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement.

Generate a long-lived page token

Use the Graph API Explorer to exchange a short-lived user token for a long-lived page token (60-day validity). This is the value for INSTAGRAM_ACCESS_TOKEN.

Find the IG Business account ID

Run GET /me/accounts?fields=instagram_business_account in the Graph Explorer. The numeric id on the returned object is your INSTAGRAM_BUSINESS_ACCOUNT_ID.

Paste, redeploy, verify

In the app, open a kit, click Post to Instagram on a kit that has an image. A successful response sets platformPostId.

Screenshot: Graph API Explorer showing instagram_business_account field

3.4   Facebook

Env varsFACEBOOK_ACCESS_TOKEN · FACEBOOK_PAGE_ID

Same Meta app as Instagram. If you've completed the Instagram section, you have everything you need — just grab two more values.

Add scopes

Request pages_manage_posts and pages_read_engagement on the same Meta app.

Get a Page-scoped token

In Graph Explorer, call GET /me/accounts. The response lists every Page you admin — each entry has its own access_token and id. Use these.

Paste, redeploy, verify

Click Post to Facebook on any approved kit. The post lands on the wired Page.

3.5   LinkedIn

Env varsLINKEDIN_ACCESS_TOKEN · LINKEDIN_PERSON_ID
Create a LinkedIn app

Go to linkedin.com/developers → Create app. Associate it with the company page you'll post from.

Request the right scope

Under Products, request Share on LinkedIn and Sign In with LinkedIn using OpenID Connect. The scope you need is w_member_social (writes UGC posts).

Run the 3-legged OAuth flow

Use LinkedIn's OAuth2 tool to authorize and exchange the code for an access token. Save it as LINKEDIN_ACCESS_TOKEN (60-day validity — set a reminder to rotate).

Get your person URN

Call GET https://api.linkedin.com/v2/me with the token — the id field is your person ID. Paste it (without the urn:li:person: prefix — the code adds that) as LINKEDIN_PERSON_ID.

Verify

Click Post to LinkedIn on a kit. LinkedIn returns a urn:li:ugcPost:... ID.

3.6   Twitter / X

Env varsTWITTER_API_KEY · TWITTER_API_SECRET · TWITTER_ACCESS_TOKEN · TWITTER_ACCESS_SECRET
⚠️ Posting requires the paid Basic tier. X's API Free tier is read-only — to post a thread you need at least the Basic plan (currently $200/month). Budget this in before you wire it up.
Apply for a developer account

Go to developer.twitter.com, apply, then subscribe to the Basic tier.

Create a Project + App

Under the Basic plan, create a Project and inside it create an App. Set the User authentication settings to OAuth 1.0a with Read and write permissions.

Copy the four credentials

From the Keys and tokens tab, copy API Key, API Key Secret, Access Token, Access Token Secret — paste each into the matching Vercel variable.

Verify

Click Post to Twitter. The code posts a 3-tweet thread; the first tweet's ID is stored as platformPostId.

3.7   TikTok

Env varTIKTOK_ACCESS_TOKEN
📝 TikTok is video-only. The Content Posting API does not accept photo uploads, so a TikTok post will fail unless FAL.ai video generation has completed (or the kit's video.url is otherwise populated).
Register at developers.tiktok.com

Sign up at developers.tiktok.com, create an app, request access to the Content Posting API. Approval can take a few days.

Add the right scopes

Request video.publish and video.upload.

Run OAuth and capture the bearer token

Walk a creator through the authorization flow — you get a 24-hour access token plus a refresh token. Store the access token as TIKTOK_ACCESS_TOKEN.

Verify

Generate a kit with FAL.ai video enabled, wait for the video to finish, then click Post to TikTok. The API returns a publish_id.

⚠️ TikTok tokens expire every 24 hours. Either build refresh-token rotation into a cron or accept that TikTok posting is a manual-supervision channel.

Substack — no setup required

Substack is a "teaser only" platform — the generator produces a 600-character teaser per kit but never posts it. Copy and paste the teaser into your Substack draft manually.

4   Part 2 — How the Ava prompt kit thinks

Every social post the generator writes is built by a single function — buildPlatformPrompt() in lib/social/ava-prompts.js. The prompt is composed from four independent dimensions, so a single article fans out into mechanically varied posts across all six channels.

The four-dimensional matrix

Every prompt is one cell in this matrix:

DimensionVariantsWhere chosen
Platform6 — instagram, tiktok, linkedin, twitter, facebook, substackFixed in PLATFORM_ORDER
Hook archetype5 — curiosity gap, bold claim, list/number, relatability, direct call-outCycles per platform via pickArchetype()
Content pillar3 — educate, entertain, sellPicked by the user when generating
CTA goal4 — grow, engage, convert, savePicked by the user when generating

6 × 5 × 3 × 4 = 360 distinct prompt shapes per article. The user picks pillar + CTA once; the platform and archetype rotate automatically.

💡 Because pickArchetype(idx) cycles archetypes by platform index, the Instagram post for a given article is mechanically guaranteed to use a different hook from the LinkedIn one — same article, five flavours of opener.

The 5 hook archetypes

Each archetype is a template function — pass the topic in and a draft hook drops out. The LLM then adapts these, but never copies them literally.

🔍 Curiosity Gap
"The one thing {topic} isn't telling you…"
Frames the post around a hidden fact the reader doesn't know yet.
💥 Bold Claim
"You don't need [common assumption] to [desired result] — here's what actually works"
Picks a fight with a widely-held belief; pays it off with the article's insight.
📋 List / Number
"3 things most clinicians miss about {topic}"
Pre-commits to a list size; reader knows the scope up front.
😩 Relatability (POV)
"POV: You've just reviewed 40 patients and none hit their targets"
A "you-too?" moment, optimised for comments and shares.
📢 Direct Call-Out
"If you're a clinician not sharing {topic} updates, you're invisible online"
Confrontational opener — high attention, used sparingly.

The 3 content pillars

The pillar instruction is prepended to every prompt and decides the post's purpose.

PillarInstruction passed to the LLM
educate "This content should build clinical authority. Lead with a surprising fact, data point, or insight that genuinely teaches something. Tone: expert but accessible."
entertain "This content should be relatable and human. Show the real experience of clinicians and patients. Tone: warm, honest, slightly vulnerable."
sell "This content should convert interest to action. Lead with a result or testimonial. Make the offer clear. Tone: confident, specific, outcome-focused."

educate dominates current usage — it's the default in the UI. The sell pillar is wired but rarely chosen because there's no UI toggle making it obvious.

The 4 CTA templates

GoalText
growFollow @gastrohealthhub for weekly clinical insights
engageComment YES below if this changed how you think about this
convertDM us or click the link in bio to learn more
saveSave this for later and share with a colleague who needs it
⚠️ The grow CTA hardcodes @gastrohealthhub at ava-prompts.js:35. The system-prompt preamble at ava-prompts.js:106 also hardcodes "Gastro Health Hub, a clinical intelligence platform focused on inflammatory bowel disease". When you fork this to Merlows, IBDHealthHub or any other brand, every one of these strings will need to come from a per-brand config object — otherwise every brand's posts will read like Gastro Health Hub.

Platform configs (per-platform overlay)

On top of pillar + CTA + archetype, each platform layers a config that controls length, hashtags, tone and media format.

Output formats

Different platforms get different parser shapes from the same LLM:

  • Instagram + TikTok — caption block, then ---SCRIPT--- divider, then a structured Reel script with HOOK / BODY / CTA / DURATION sections.
  • LinkedIn + Facebook — caption only, hashtags extracted post-hoc with a regex.
  • Twitter — three labelled tweets (TWEET 1:, TWEET 2:, TWEET 3:) parsed into an array.
  • Substack — raw teaser, stored but never posted.
📝 Is this really "Ava"? The Personal Brand Launch methodology (Ava, @personalbrandlaunch, 939k Instagram followers) optimises for consumer-virality on personal accounts: hook-first, scroll-stopping, single-CTA discipline. This kit borrows the structural parts — archetype rotation, hook-first writing, one CTA per post — but applies them to a clinical B2B niche where the actual voice has to stay credible. So it's Ava-as-skeleton, clinical-authority-as-flesh. Don't expect the same engagement numbers as a consumer brand using the same archetypes.

The image pipeline has three call sites and one bug. The bug was fixed in the same session that produced this guide; this section explains what was wrong and what to consider next.

The bug — fabricated model slugs

Until this session, the allow-list referenced four model slugs that do not exist on OpenRouter:

Before (bogus)

google/gemini-3.1-flash-image-preview-20260226 sourceful/riverflow-v2-fast sourceful/riverflow-v2-pro bytedance-seed/seedream-4.5

None present in OpenRouter's live model catalog. The Gemini slug had a fabricated date suffix; the inline comment in the same file even contradicted the code.

After (verified 2026-05-15)

google/gemini-3.1-flash-image-preview openai/gpt-5.4-image-2

Both slugs verified against https://openrouter.ai/api/v1/models. Gemini 3.1 Flash Image Preview ("Nano Banana 2") is now the primary; gpt-5.4-image-2 is the fallback for outages.

✨ Both lib/social/media.js and lib/social/handlers/image.js now use the verified slugs. generateImage() and generateImageFast() share a single generateWithFallback() helper that tries the primary, falls back on transient errors, but short-circuits on auth / credit failures.

What changed and where

// lib/social/media.js — IMAGE_MODELS
const IMAGE_MODELS = {
  'google/gemini-3.1-flash-image-preview': { modalities: ['image', 'text'] },
  'openai/gpt-5.4-image-2':                { modalities: ['image'] },
};
const DEFAULT_IMAGE_MODEL  = 'google/gemini-3.1-flash-image-preview';
const FALLBACK_IMAGE_MODEL = 'openai/gpt-5.4-image-2';

The LinkedIn / Facebook branch that previously routed to the non-existent sourceful/riverflow-v2-fast has been collapsed — all platforms now use the same default model with the aspect ratio set per platform via image_config.aspect_ratio.

Recommendations

1. Move the allow-list to environment variables

Each brand iteration (Vance, Merlows, IBDHealthHub) may want different models. Today the list is hardcoded. Plan:

// future
const ALLOWED = (process.env.SOCIAL_IMAGE_MODELS || 'google/gemini-3.1-flash-image-preview,openai/gpt-5.4-image-2').split(',');

This lets brand forks override the model chain without code edits — just a Vercel env var.

2. There is no free image tier on OpenRouter

As of May 2026, OpenRouter exposes only two text-to-image models, both paid. The realistic per-image floor is ~$0.0005 (Gemini Flash Image) to ~$0.015 (gpt-5.4-image-2). Plan budgets at roughly $1.50 per 100 articles assuming four images per article and the default model.

3. Consider FAL.ai FLUX schnell for high-volume brands

FAL.ai's FLUX schnell sits at roughly $0.003/image but is dramatically faster and more reliable than routing through OpenRouter. For brand iterations doing 50+ articles a week, the latency win is worth the small unit-cost premium. You're already wired into FAL.ai for video — re-using the same key is one extra fetch call.

4. Add per-platform aspect-ratio env overrides

The current code hardcodes 4:5 for Instagram and 1:1 for LinkedIn / Facebook in PLATFORM_CONFIGS. Brand iterations that want full-width LinkedIn images shouldn't need a code edit — push these to a brand config too.

5. The text LLMs are fine — leave them on the free tier

meta-llama/llama-3.3-70b-instruct:free for prompt crafting and deepseek/deepseek-chat-v3-0324:free for video prompting are real, free, and reliable. No change needed.

How to verify the fix

Deploy

Run vercel --prod --yes from the project root.

Generate a kit

In the app, pick an article, click Generate kit. The response should include non-empty image.url fields for Instagram, TikTok, LinkedIn and Facebook.

Watch the model field

Each image object in the kit JSON now has a model field. It should read google/gemini-3.1-flash-image-preview. If you see openai/gpt-5.4-image-2, the primary failed and the fallback caught it — investigate the Vercel function logs.

If both fail

Likely OpenRouter credits are exhausted. Check openrouter.ai/credits. The thrown error will say so.

6   What's still missing

This walkthrough surfaces three follow-on tasks — each will get its own plan and PR:

1. Build the Connections pane
Replace the empty placeholder at index.html:3140 with a token-paste UI per platform, a test-post button, and a green/red status pill. Eliminates the Vercel-dashboard ritual for every new brand fork.
2. De-brand the prompt kit
Extract the hardcoded "Gastro Health Hub" / "@gastrohealthhub" / "inflammatory bowel disease" strings from ava-prompts.js into a per-tenant brand config object loaded by handle.
3. Move image models to env
Replace the hardcoded IMAGE_MODELS / ALLOWED_MODELS with a SOCIAL_IMAGE_MODELS env var so brand iterations can swap models without code edits.
4. (Optional) Token rotation cron
Instagram, Facebook and LinkedIn tokens expire every ~60 days; TikTok every 24 hours. A simple cron that exchanges the refresh token and updates the env value would prevent silent posting failures.

7   Glossary

Archetype
One of five hook templates (curiosity gap, bold claim, list/number, relatability, direct call-out) used to vary how each platform's post opens.
Ava
Shorthand for the Personal Brand Launch methodology by Ava (@personalbrandlaunch, 939k Instagram followers). This generator borrows the structural parts — archetype rotation, hook-first writing — but applies them to clinical B2B content.
Content kit
The bundle of platform-specific posts the generator produces from one article. Stored in Vercel KV at social:kit:<id>.
CTA goal
One of four call-to-action templates (grow, engage, convert, save) selected when generating a kit.
FAL.ai
Third-party video generation service. The pipeline uses FAL's Kling v2.1 model for 10-second Reel / TikTok videos.
Graph API
Meta's HTTP API that handles both Facebook and Instagram. The current code targets v19.
OpenRouter
API gateway that routes calls to dozens of LLM and image-generation providers behind a single API key.
Pillar
One of three content purposes (educate, entertain, sell) selected when generating a kit. Sets the tone of every post in the kit.
Substack teaser
A 600-character teaser the generator produces for newsletter use. Never auto-posted — copy-pasted manually.
UGC post (LinkedIn)
LinkedIn's "User Generated Content" post type. The endpoint is POST /v2/ugcPosts.
